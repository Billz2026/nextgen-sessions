# Scheduled release policy

`scheduled-releases.json` is metadata-only. Scheduled entries may include the artist, title, release time, artist path and future release slug, but must never contain a YouTube video ID, watch URL, embed URL or thumbnail URL before release.

The public catalogue remains the authority for playable media. A scheduled release becomes eligible for public release pages, artwork endpoints, sitemap entries and YouTube links only after it is public in the verified catalogue and its publication time is not in the future.
