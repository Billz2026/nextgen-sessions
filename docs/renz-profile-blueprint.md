# Featured artist profile blueprint

Renz Cole is the reference implementation for the remaining featured artist pages.

## Required profile structure

1. Clean artist portrait and accurate identity copy.
2. Quick navigation for Featured, Latest, Albums, All songs and About.
3. One main YouTube player only.
4. Artwork and Play now controls start songs through the main player without forcing the visitor away from the catalogue.
5. A compact now-playing bar remains visible while the visitor continues browsing.
6. Featured Release stays under editorial control.
7. Latest Release and All Songs update from the official release catalogue.
8. Album sections appear only when a verified album exists.
9. Album counts describe standalone videos, not the album's total track count.
10. Related artists must match the artist's actual musical lane.
11. Navigation, metadata, accessibility and mobile behaviour must match the main site.

## Renz Cole release rule

Outside Till Late remains the latest public release until Heatwave is published and enters the official UK Rap & Grime playlist catalogue. Heatwave must not be manually exposed before its YouTube release. Once the catalogue refreshes, it should appear once, sort newest-first and become the automatic latest release.
